# 观点提炼规范（数据清洗核心 · v21 四层判断逻辑）

> **v21 重大升级**：观点判断逻辑由「数量下限 + 章节覆盖表 + 补读」升级为「**四层升级闸**」。
> 旧逻辑只防「漏」，管不了「重、虚、散」；条数波动（20 多 vs 50 多）的根因是结构单元切分粒度全凭临场手感。
> 新逻辑把判断标准从「切了多少块」换成「每块是不是一个真命题、属哪一层、和谁相连」。
> 数量下限**保留但降级为最后一道安全网**，不再是主角。详见下文第一节与第二节。
>
> **v43 防漏升级（2026-11-20，用户强制）**：针对"大书只提几十条"的系统性漏观点，新增**闸 0 命题池穷举**（结构必须先于树、先穷举后聚类，禁止先定核心数/配额）、**思想密度判定**（区分思想书与叙事书，杜绝"宁缺毋滥"被滥用）、**大书下限提高 + 覆盖率/倍率硬闸**。这是"多呈现鲜明观点、少罗列空话"的落地规则，优先于下文所有旧条款。详见第零章与闸 4。
>
> **v44 理念校准（2026-11-20，用户强制）**：v43 的下限/覆盖率/倍数只是**防"完全没挖"的地板**，不是目标——"达标"只证明没漏得离谱，绝不证明挖到位。思想密集书（《资本论》、稻盛和夫等大家/理论经典）观点多、刁钻、突出，应**穷尽挖掘**：铁律 4 上限不封顶且条数 ≥ 下限 ×1.5、铁律 5 六角掘进把密集单元拆成多条、铁律 6「不重复」靠消去测试而非少列、停止看边际产出而非数字达标。**禁止贴着下限交差。** 详见第零章铁律 4–6。

## 零、v43 防漏三铁律（强制执行，优先级最高）

大书/名著/思想书只提几十条，是**结构性漏观点**，不是"精炼"。以下三条为铁律，违反即判不合格。

### 铁律 1 · 命题池穷举，先于一切结构（禁止"先搭树再填"）

**正确顺序（强制）**：
1. **逐章/逐单元通读**，对每个有独立主旨的单元跑准入四问，**先穷举命题池**——不问要提炼多少条，只问"这里有没有一个真命题"。
2. 得到命题池后，**再**把命题归成「核心→分层→基础」三层树、建 links。
3. 树是命题池的**结果**，不是**模具**。

**禁止**：先定"9 个核心、每核 2–3 条"再往里填——这等于给观点设配额上限，必然压缩密度、漏掉放不进格子的命题。截图中的 AI 正是栽在这里。

**命名信号**：出现"我先规划结构/先定 N 个核心/每个核心几条"=违规；出现"我逐章过一遍，得到命题池 N 条，再归并"=合规。

### 铁律 2 · 思想密度判定：思想书必须多呈现，空话书才少列

用户口径（写死）：**观点多且鲜明就多呈现；洋洋洒洒但思想空空，就少罗列几条。** 因此先判"思想密度"，再决定下限松紧：

| 类型 | 判定信号 | 下限策略 |
| --- | --- | --- |
| **思想密集书**（名著、理论经典、大家论断、观点鲜明的practical） | 每章几乎都有可检验主张、常有反常识机制、原文多"我认为/关键在于/本质是" | **下限上调**：按页数取高档，覆盖率必须接近 1 |
| **思想稀疏书**（小说、游记、随笔、流水账、纯案例堆砌） | 通篇叙事描写、少可检验主张、观点需读者自行归纳 | 下限可下调，宁缺毋滥 |

**铁律：名著 / 有影响力作者 / 理论经典，一律视为思想密集书，禁止用"观点密度低/叙事类"豁免。** 这类书 2000 页只出 40 条 = 漏，不是精炼。

### 铁律 3 · 覆盖率与深读倍数是硬闸，不是提示

- **有独立主旨章节覆盖率必须 ≥ 0.75**（理想接近 1）；低于此值不得交付，须回到未覆盖章节补挖。
- **深读倍数**（观点条数相对速读摘要）：理论/思想书应达速读的 **3–5 倍**；显著低于 2 倍视为漏。
- 这两个指标在 `validate_data.py` 中为 **error 级**（旧版 warn 已升级），不达标直接 fail。

### v44 理念校准（2026-11-20，用户强制）——下限是地板，不是天花板

**用户原话**：「保底始终只是保底……像《资本论》、稻盛和夫这样的文章，思想密度很高、观点很多很突出很刁钻，应该想着如何深度挖掘出这样的观点，主要是不重复的……不能完全贴着下线要求去做。」

前面所有下限/覆盖率/倍数，作用只有一个：**防止"完全没挖"的偷懒**。它们能证明"没漏得离谱"，**永远不能证明"挖到位了"**。思想密集书（名著/理论/大家）的命题池本就远超下限——72 条对它是及格，也是亏欠。因此追加三条铁律，优先级与铁律 1–3 相同：

### 铁律 4 · 穷尽挖掘，上限不封顶

- **条数 = 命题池真实密度，不是下限的达标结果。** 思想密集书产出的条数应**显著高于**下限（经验值：≥ 下限 × 1.5），且**不设上限**——命题池有多少个彼此不可还原的真命题，就出多少条。
- **禁止"达标即停"**：达到下限、覆盖率 0.75、倍数 2，**都不构成停止理由**——这些只是"底线已过"，不是"挖掘完成"。停止条件见铁律 6。
- **刁钻优先**：同等条件下，优先挖反常识、反直觉、机制反转、被忽略的前提、失效边界这类"有锐度"的命题——它们是高价值观点的富矿，也正是思想密集书最该呈现的东西。

### 铁律 5 · 六角掘进：一个密集单元挖出多条，不压成一条

思想密集的章节/段落，往往同时藏着多个**彼此不可还原**的命题。禁止把它们压进一个 title。对高价值单元逐个扫这六个角，每角能站住一个独立命题就**单列一条**：

| 角 | 追问 | 产出 |
| --- | --- | --- |
| ① 主张 | 作者断言了什么？ | 核心/分层命题 |
| ② 机制 | 为什么成立、怎么发生？ | 因果链命题（学科原理） |
| ③ 前提 | 依赖什么没说出口的假设？ | 前提命题（premise.assumption） |
| ④ 边界 | 什么条件下失效？ | 边界命题（counter.kind=边界） |
| ⑤ 反转 | 有无反常识/早期优势后期病因？ | 反转命题（insights 或独立条） |
| ⑥ 推论 | 能迁移到什么别的领域？ | 应用/方法命题 |

**密度损失的主要来源**：把六角压成一条 title——比如"劳动二重性"一章，其实含「使用价值/价值二因素」「具体/抽象劳动」「劳动生产力与价值量反比」「等价形式」等多个独立命题，压成一条就丢了大半。密集书应逐角展开成多条。

### 铁律 6 · 不重复 ≠ 少列；停止看"边际产出"不看"数字达标"

- **"不重复"靠"每条锁定一个不可还原命题"实现，不靠"少列几条"实现。** 禁止拿"避免重复/宁缺毋滥"当压缩密度的挡箭牌。
- **不重复判定 = 消去测试**：删掉这条，读者是否丢失一个**其他任何条都覆盖不了**的信息？丢失 → 保留（哪怕和别的条表面相似）；完全不丢 → 才是同义，合并、另一场景降为 support。
- **停止条件改写**：
  - ❌ 错误：条数达到下限 / 覆盖率达标 / 倍数达标 → 停。
  - ✅ 正确：**逐章二次扫读，边际产出为零才停**——即"再通读一遍，找不到任何一条与现有观点都不重复的新真命题"。有一章只扫一遍就过，不算挖完。
- **自检追加**：交付前必须能回答"我二次扫读时，哪一章又补出了新观点？"——答不出，说明只扫了一遍就停，密度大概率不够。

## 一、四层升级闸（观点判断主逻辑 · 强制执行）

### 闸 1 · 入口分流：按图书类型换拆法，不套同一模板

提炼前先判定图书类型，类型决定「什么算一条观点」：

| 图书类型 | 判定信号 | 一条观点通常是什么 | 下限浮动 |
| --- | --- | --- | --- |
| **实用类** | 方法论、步骤、工具、可直接照做 | 一条行动建议/一个可操作步骤 | 常规下限 |
| **理论类** | 概念密集、机制解释、学科原理 | 一条原理/机制/因果链 | 常规下限 |
| **叙事类** | 人物传记、案例故事、随笔散文 | 从人物成败/原则动机/冲突中提一条判断 | **可低于下限**（不强拆） |
| **混合类** | 理论+案例交织（多数商业书） | 以理论主干切，案例作支撑 | 常规下限 |

规则：**随笔、散文、确属思想稀疏的书，宁可少而精，不为凑数强拆**。下限公式对叙事类仅作参考，不强制——但**必须按第零章铁律 2 判定为"思想稀疏"才可豁免**；名著、理论经典、有影响力作者的书一律不得套用此豁免，哪怕原文叙事性强。

### 闸 2 · 逻辑单元：按主旨切，不按章节切（准入四问）

**核心原则**：章节是文法单位，主旨是逻辑单位，二者不是一一对应。一个章节可能含多个独立主旨，多个章节也可能说的是同一件事。按章节切必然产生「同义拆多条」或「多主旨并为一条」。

**准入四问**——每条观点必须同时通过，否则不收：
1. **独立性**：能否脱离原章节独立成立？（只是承接上文的半句话不收）
2. **非同义**：理由是不是结论的翻版？（问「为什么」，答不出的就是纯断言，不收）
3. **可检验**：能否写出隐含假设，并回答「假设不成立时结论还站得住吗」？（填不出假设机制的不收）
4. **有边界**：能否说出它可能失效的条件或范围？（放之四海皆准的空话不收）

**同义合并**：两条观点若底层主张相同、仅场景或措辞不同，合并为一条，把另一场景降为 `support` 证据。

> 反面清单（一律剔除）：纯断言无理由、同义反复、关键词堆砌（「赋能」「闭环」「抓手」这类无具体内容）、仅为衔接的过渡段、无独立主张的案例复述。

### 闸 3 · 分层结网：每条打层次标签 + 建连接

**层次标签 `level`**（四层，沿用思维模型分层）：

| level | 含义 | 判定 |
| --- | --- | --- |
| `哲学视角` | 世界观、价值判断、人之为人的主张 | 回答「该不该/什么是本质」 |
| `学科原理` | 可验证的机制、规律、因果模型 | 回答「为什么、机制是什么」 |
| `方法流程` | 可执行的步骤、方法、框架 | 回答「怎么做」 |
| `经验技巧` | 具体场景的窍门、注意事项 | 回答「某个具体情境下怎么做更好」 |

规则：
- 每条观点**必须**有且仅有一个 `level`；全书层次分布应合理——理论书以 `学科原理` 为主，实用书以 `方法流程` 为主，避免全部堆在某一层。
- 每条观点**必须**写 `links`：说明它与哪些编号的观点构成 `支持 / 反驳 / 细化 / 前提 / 应用` 关系。例：「立论根基，被 #6 支撑，被 #3 应用」。
- `links` 至少给出一条关系；确实孤立的观点写「独立命题，暂无强连接」，不得留空。

**洞察页**来自分层结网的副产品：专找「今天的解药是明天的病因」「早期优势后期反转」这类**机制反转**，按反常识权重降序，3–7 条。不是随便挑几句反常识的话。

### 闸 4 · 密度校验：用结构指标取代纯数量

校验器（validate_data.py）除字段合规外，校验密度指标（**v43：覆盖率/深读倍数升级为 error 硬闸**）：
- **论点覆盖率**（error，≥0.75）：有独立论点的章节数 / 总章节数，应接近 1；低于 0.75 不得交付，回未覆盖章节补挖
- **原理层占比**（warn）：`学科原理` + `哲学视角` 的条数占比，理论书应过半，实用书可偏低
- **连接度**（warn）：有 `links` 且非「独立命题」的观点占比，应过半
- **深读倍数**（error，思想/理论书 ≥2，理想 3–5）：观点条数 / 速读摘要条数

条数本身退化为参考值：**20 条全是有连接的真命题，优于 50 条同义拆分的清单**——但**前提是命题池已穷举、覆盖率达标**；不能拿"真命题少"掩盖"根本没挖全"。

**v44 校准**：上面"20 条优于 50 条"只在**同义拆分**时成立，绝不能推广成"少即是多"。对思想密集书，**下限从不是目标**：条数应显著高于下限（≥ 下限 × 1.5），广度穷尽（六角掘进）与不重复（消去测试）同时成立才算挖到位。判据是"还有没有没被挖出的不重复真命题"，不是"够不够数"。

## 二、数量下限（降级为最后安全网）

四层闸跑完后，用下表**兜底复查**：若条数低于下限，回到论点最密集的章节挖第二轮；但仍须逐条通过准入四问，不得为达标放宽标准。

> **v44 强制澄清**：本表是**防"完全没挖"的地板，不是目标、不是配额**。思想密集书（名著/理论/大家）产出**应显著高于对应下限（≥ ×1.5）且上不封顶**——达到下限只说明"没偷懒到离谱"，绝不说明"挖够了"。禁止把"卡在下限附近"当成合格交付。真正决定条数的是命题池里有多少个不重复的锐利命题（铁律 4/5/6）。

| 文档规模 | 观点数量下限（安全网，非目标） |
| --- | --- |
| 单本书 ≤ 200 页 / ≤ 8 万字 | ≥ 12 条 |
| 单本书 200–400 页 / 8–20 万字 | ≥ 20 条 |
| 单本书 400–800 页 / 20–40 万字 | ≥ 40 条 |
| 单本书 800–1500 页 / 40–80 万字 | ≥ 60 条 |
| 单本书 > 1500 页 / > 80 万字（大部头/全集） | ≥ 72 条，或按「有独立主旨章节数 × 0.8」取高者 |
| 多篇文档合集 | 每篇 ≥ 15 条，合计 ≥ 30 条 |
| 短文 / 报告（< 2 万字） | ≥ 6 条 |
| **思想密集书（名著/理论/大家）** | **在上表基础上再上浮一档，覆盖率必须 ≥0.75** |
| 叙事类 / 随笔 / 观点密度低的书 | 可低于下限（须第零章铁律 2 判定确认思想稀疏，禁止随手豁免） |

## 三、章节覆盖表（配合闸 2 使用）

1. 从目录页、章标题、Markdown 标题、`===== PAGE N =====` / `===== CH N =====` 标记中，列出全部结构单元。
2. 建表：`章节 | 该章主旨数 | 归并后观点编号 | 是否通过四问`。
3. 逐章提炼，**注意跨章主旨合并**——不同章节讲同一件事时只留一条，另一处标进 `support`。
4. 覆盖表里有章节产出 0 条且确有独立主旨的，定向回原文补读；确实无独立主张的（纯叙事/过渡），留空并在表内注明「无独立主旨」。

## 四、四步提炼法（每条观点的字段生产）

对每一条通过四问的主旨，按下面顺序产出字段：

1. **定 title + level**：一句完整判断（20–40 字，含核心概念），并判定四层之一。
2. **拆推演 logic**：4–5 步因果链——前 3–4 步「现状 → 矛盾 → 机制 → 条件」，末步以 `推论：` 开头，给可迁移结论。
3. **配支撑 support**：3–6 条实证（原文金句、数据、案例、表格、学者理论、历史事件），每条带页码，格式 `P16` / `P16-17`。引用原文用「」。
4. **炼金句 + 定出处**：`quote` 一句能独立传播的凝练表述（≤45 字，可独立传播，不与 title 重复）；`src` 写 `第X章 P12-18`，页码用 `P` 格式。
5. **定行动建议 actions**：回原文找作者明确指引（`k:"author"` + `p` 页码）；不足则据本条推演（`k:"theory"`，`p` 留空）。每条 4–5 条，**author 全部排在 theory 之前**。三段式 `何时｜做法｜到位`，全角 `｜` 分隔。
6. **补前提 premise**：`{premise:[{t,origin}], assumption:[{t,origin}]}` 各 1 条。原文明确记 `原文`（渲染标「作者观点」），需推断记 `推测`（渲染标「推演」）。
7. **补反例/边界 counter**：`{t, origin, kind}`，`kind` 只能「反例」或「边界」，`origin` 为「原文」或「推演」。
8. **补连接 links**：按闸 3 写出与其他观点的关系。

### 字段结构与质量

| 字段 | 结构 | 要求 |
| --- | --- | --- |
| `level` | 字符串 | 只能是 `哲学视角`/`学科原理`/`方法流程`/`经验技巧`，每条恰好一个 |
| `links` | 字符串 | 与至少一条其他观点的关系，或「独立命题，暂无强连接」 |
| `title` | 字符串 | 完整判断句，含核心概念，20–40 字；核心词可被加粗强调 |
| `chap` | 字符串 | `第X章 · 章节主题` 或 `引言 · 主题` |
| `logic` | 数组 | 4–5 步，末步 `推论：` 开头；每步 15–50 字，口语化 |
| `support` | 数组 | 3–6 条，含具体数字/人名/案例/原文；每条 20–80 字，句末 `P16` |
| `actions` | 数组 | 4–5 条 `{k,p,t}`；`k` 为 `author`（带 `p`）或 `theory`（`p` 空）；author 排前；`t` 为三段式 |
| `premise` | 对象 | `{premise:[{t,origin}],assumption:[{t,origin}]}` 各 1 条；origin 为 `原文`/`推测` |
| `counter` | 对象 | `{t,origin,kind}`；kind 为 `反例`/`边界`，origin 为 `原文`/`推演` |
| `quote` | 字符串 | 一句，≤45 字，可独立传播，不与 title 完全重复 |
| `src` | 字符串 | `第X章 P16-24` / `引言 P16-24`，页码只写 `P16`/`P6-7`，不加括号、不写「书页/PDF/PAGE」 |

## 五、反常识洞察（单独产出）

常规观点之外，专门做一轮「机制反转筛查」：
- 找与大众直觉相反、但作者有证据的断言，尤其是「某要素早期是优势、后期变障碍」「看似解法其实是病因」这类结构反转。
- 每条洞察格式：`<b>加粗核心反转</b>——为什么反常识 + 依据`。用 HTML `<b>`，生成器保留。
- 每份文档筛 **3–7 条**，放进 `insights`，`group` 为文档下标（0/1/…）。**按反常识权重降序：`n=1` 最反常识**。
